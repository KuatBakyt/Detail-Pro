# Detail Pro

Адаптивный сайт по предоставленному макету на HTML, CSS и JavaScript. Локальные изображения; минимальные анимации появления; поддержка prefers-reduced-motion.

Запуск: статический сервер из корня репозитория. Для Vercel: Other, без установки и сборки, корневая папка проекта.

Функции: мобильное меню, карусель услуг, фильтры и просмотр работ, демонстрационное сравнение изображения, подготовка запроса разработчику в WhatsApp. Номер задаётся в script.js. Показатели и портфолио иллюстративные. Изображения извлечены из пользовательского макета; для реального бизнеса замените их фотографиями студии.
